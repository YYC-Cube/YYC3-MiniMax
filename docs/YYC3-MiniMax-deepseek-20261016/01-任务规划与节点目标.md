# 📋 任务规划与节点目标

## 规划总则

> **执行有规划，规划有节点，节点有目标，目标可评估**

## 一、总体目标

对 AI Family 8 Agent 与 ReAct-C 九步闭环做架构解耦：`agent-orchestrator` 不依赖 UI/Next.js；
8 Agent 统一六元组接口；九步以状态机实现（Step7 不达标回环 Step5，复检 ≤2 轮）；
UI 只发命令、worker 执行、事件回流；所有 Agent 调用走 ports（适配器可替换 local/vLLM/Registry）；
全链留痕（traceId/耗时/Token/模型名/风险标签）；失败可重试、可回滚、可人工接管。
