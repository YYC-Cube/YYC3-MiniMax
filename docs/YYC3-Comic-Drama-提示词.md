你是一位精通企业级 SaaS 与 AI 视频生产工具（对标剪映专业版、Pixmax、Linear、蚁小二、Unreal Movie Render Queue）的资深产品设计师与设计系统架构师。请为「YYC³ AI Family · Comic Drama」——一个 AI 漫剧（漫画短剧）工业化生产平台——设计完整的前端界面系统，并输出可直接进入 Figma 交付的变量、组件、页面与原型。

【产品核心定位】
以 8 拟人化 Agent（YYC³ AI Family）协同驱动的「小说→剧本→分镜→图像→视频→成片→运营」六阶段漫剧/短剧工业化生产系统，采用 ReAct-C 九步闭环编排引擎，支持多平台一键分发与数据回流。系统具备完整的认知可观测、人机共驾、学习沉淀与主动智能能力。

【产品四大功能域 + 认知层】

1. 生产全链路：剧本 → 分镜 → 角色/场景资产 → 图生视频批量生成 → 配音字幕 → 质检门禁
2. 剪辑合并：多轨道时间线编辑器（对标剪映），智能粗剪，字幕/BGM/转场，FFmpeg 渲染导出
3. 平台管理：项目剧集中心、资产中心、任务编排监控、数据看板、成本中心、RBAC 权限
4. 一键推送：多平台（抖音/视频号/B站/快手/小红书）账号矩阵、格式自适应、定时分发队列、发布回执看板、数据回流
5. 认知增强：Agent 实时轨迹、置信度分流、多 Agent 议事厅、驾驶模式 L0/L1/L2、主动提示
6. 学习沉淀：Learning Inbox、三层记忆、Prompt Registry、RAG 索引、世界观图谱

【硬性要求】

- 桌面端优先（1440px 主画板，1980×1020 大屏基准），深色唯一主题，禁止浅色模式与移动端布局
- 风格：深色工业科技风——深藏青底色 + 青绿主色 + 蓝紫辅助，专业克制，无霓虹糊边、无卡通、无 3D 渲染、无粒子爆炸、无异形组件
- 字体：Inter + 思源黑体，数字与代码用 JetBrains Mono / SF Mono（tabular-nums）
- 所有页面给出空态 / 加载态 / 错误态 / 无权限态四种状态
- 所有列表给出批量操作栏；所有长任务给出进度与「人工接管」入口
- 组件命名遵循 shadcn/ui 语义（Button、Dialog、Table、Tabs、Sheet…），便于设计-代码一一映射
- 所有颜色/圆角/间距/字号绑定 Design Token，禁止硬编码
- 每个 Agent 决策必须可展开查看 ReAct-C 轨迹，不允许黑盒
- 所有 Agent 输出必须带 confidence，UI 必须呈现三档（≥0.9 青绿 / 0.6–0.9 橙 / <0.6 红）
- AI 不可用时，页面必须显示降级提示 + 手工替代路径，禁止静默失败
- 全局与单任务层均可切 L0/L1/L2，禁止锁定单一模式
- 所有进入 Learning Inbox 的样本必须经人工审核才入库
- 所有记忆条目支持"遗忘"，合规友好
- Prompt 变更必须走版本管理 + 90 天审计
- 议事厅仲裁建议必须可被人工否决，禁止强制采纳
- 同类主动提示支持"本周不再提示"
- P14 成本中心必须展示每个 Agent 的成本，禁止 AI 成为成本黑洞
- 除无限循环动画外，全部动效 ≤300ms

### 6.2 业务专属动效

- \*\*五阶流水线\*\*：进行中节点呼吸闪烁（透明度 30%↔100%，2s 循环），连线有光点从左向右流动（3px 圆，2s 循环）
- \*\*进度条\*\*：已完成部分渐变填充 + 微光流动效果，加载时平滑推进无跳变
- \*\*数据更新\*\*：数值变化时数字滚动翻牌效果（200ms），图表数据从下至上渐进绘制
- \*\*状态切换\*\*：运行/完成/失败状态切换时，图标缩放+颜色过渡，无硬切
- \*\*通知弹出\*\*：从右上角滑入，带轻微弹性，停留 4s 后滑出
- \*\*告警\*\*：边框粉色闪烁 3 次（0.5s/次）+ 轻微震动 2px
- \*\*页面切换\*\*：内容淡入 + 上移 8px（240ms），无夸张转场

### 6.3 认知专属动效

| 场景 | 动效 | 参数 |
| --- | --- | --- |
| Agent 思考 | 头像外圈 3 圈同心圆扩散（专属色 → 透明） | 2s 循环 |

| 记忆激活 | 命中记忆的卡片边线紫光流动 | 3s 循环 |

| 九步回环 | Step7 → Step5 虚线绘制动效 + 回环计数 +1 | 500ms |
| 驾驶模式切换 | 全局色温微变（L0 青绿 / L1 蓝 / L2 橙） | 300ms |
| 主动提示 | 从浮窗顶部滑入 + 轻微弹跳 | 250ms |

### 6.4 加载与空状态

- 页面加载：骨架屏，布局与真实内容一致，灰色呼吸动效
- 局部加载：小型环形加载器，品牌色旋转动画
- 空状态：统一插画 + 文案 + 引导按钮，深色风格适配；新增"智能引导态"（Agent 建议下一步）

### 6.5 数据可视化增强

- 折线图：线条主色，填充区域从主色到透明渐变；hover 显示十字准线+数据浮层
- 环形图：扇区分段带 1px 间隙，hover 扇区放大 1.05 倍，中心显示数值
- 柱状图：柱子渐变填充，顶部圆角，hover 高亮
- 雷达图：网格半透明，数据区域半透明填充，对比数据集用不同颜色区分
- 所有图表支持平滑动画：数据变更时图形平滑过渡，时长 300ms

### 6.6 认知交互规则

1. \*\*L0 全自动模式下\*\*：所有 Agent 决策以"通知"形式进入顶栏铃铛，用户 5s 内可撤销
2. \*\*L1 半自动模式下\*\*：所有 \`confidence < 0.9\` 的决策阻塞在 AgentDecisionSheet
3. \*\*L2 人工主导模式下\*\*：Agent 只输出建议卡，不自动执行任何写操作
4. \*\*议事厅触发\*\*：仅当同一议题上 ≥ 2 个 Agent 输出置信度差异 > 0.2 且方向冲突时
5. \*\*Learning Inbox 推送\*\*：每日 18:00 汇总推送一次（可配置频率）
6. \*\*降级路径\*\*：任一 Agent 不可用 → 顶栏铃铛 + 该 Agent 头像灰化 + 相关页面出现"降级模式"提示条 + 提供手工替代路径

## 八、红线与约束（设计必须遵守）

| 红线 | 设计体现 |
| --- | --- |
| 密钥零入库 | 界面永不出明文密钥/Token；授权状态用徽标表达 |
| NAS 单一路径 | 文件选择器仅展示逻辑目录树，不出现本地绝对路径 |
| 端口规划 | 前端 2xxxx / 后端 25xxx / 中间件 3xxx（仅开发文档层，不影响视觉） |
| 命名规范 | 角色「知遇·伯乐」= \`zhiyu-bole\`，界面文案与代号一致，禁止 \`qianli\` 残留 |
| 质检红线 | 格物·宗师 <80 一律打回 → 设计不得提供「强制放行」无确认捷径 |
| 四域色 | 青绿=生产 / 紫=剪辑 / 蓝=管理 / 珊瑚=推送，全局唯一映射 |
| 8 Agent 平等 | 头像尺寸一致（32px/80px）、亮度一致，仅靠专属色区分角色 |
| 深色唯一主题 | 禁止浅色模式（本项目为指挥中心大屏），禁止移动端布局 |
| 动效时长 | 除无限循环动画外，全部 ≤300ms |
| 禁止项 | 卡通、3D渲染、粒子爆炸、霓虹糊边、异形组件、硬编码色值 |
| \*\*认知可解释\*\* | 每个 Agent 决策必须可展开查看 ReAct-C 轨迹，不允许黑盒 |
| \*\*置信度强制\*\* | 所有 Agent 输出必须带 confidence，UI 必须呈现三档 |
| \*\*降级必可见\*\* | AI 不可用时，页面必须显示降级提示 + 手工替代路径，禁止静默失败 |
| \*\*驾驶模式必可切\*\* | 全局与单任务层均可切 L0/L1/L2，禁止锁定单一模式 |
| \*\*学习必可审\*\* | 所有进入 Learning Inbox 的样本必须经人工审核才入库 |
| \*\*记忆必可忘\*\* | 所有记忆条目支持"遗忘"，合规友好 |
| \*\*Prompt 必版本化\*\* | Prompt 变更必须走版本管理 + 90 天审计 |
| \*\*议事厅不越权\*\* | 议事厅仲裁建议必须可被人工否决，禁止强制采纳 |
| \*\*主动提示不骚扰\*\* | 同类主动提示支持"本周不再提示" |
| \*\*AI 成本可见\*\* | P14 必须展示每个 Agent 的成本，禁止 AI 成为成本黑洞 |
| \*\*四域色不变\*\* | 认知色只做辅助，不得替代四域色映射 |
| \*\*8 Agent 平等不变\*\* | 认知增强不改动 8 Agent 的视觉平等原则 |

第六部分 · Prototype 连线要求
投喂给 Figma AI 时说明原型连线：
【Prototype · Auth 域闭环】

主链路（金牌路径）：
  A01 登录 →（成功 + 无 MFA）→ /dashboard
  A01 登录 →（成功 + 有 MFA）→ A05 验证 → /dashboard
  A01 登录 →（失败 5 次）→ A09 锁定 →（倒计时结束）→ A01
  A01 → 忘记密码 → A03 →（发送成功）→ 邮件点击 → A04 →（重置成功）→ A01
  A01 → 立即注册 → A02 →（成功）→ A07 引导 → /dashboard
  邮件邀请 → A06 →（注册并加入）→ A07 → /dashboard
  任意页面 →（会话过期）→ A08 expired →（重新登录）→ A01
  任意页面 →（无权限访问）→ A08 403 →（返回）

交互细节：

- 页面切换：淡入 + 上移 8px（240ms motion-slow）
- 表单错误：卡片边框粉色闪烁 3 次 + 震动 2px
- 按钮 loading：文案前插入 16px 环形加载器
- OTP 输入：自动跳格 150ms（motion-fast）
- 成功态过渡：1.2s 后自动跳转，跳转前内容淡出---

第八部分 · Auth 域红线补充
红线
设计体现

不新增第五域色
Auth 域使用中性底 + accent 主色，四域色仅作背景光晕/角色标装饰

密码永不明文
密码框默认隐藏；「记住我」只存 Token 不存密码；界面上任何位置不出现密码

错误提示不泄漏账号存在性
「忘记密码」不区分邮箱是否存在，一律成功态

MFA 不可绕过
已开 MFA 的账号登录必须完成验证，无「跳过」入口

验证码有频控
倒计时 UI 必须体现 60s 频控；连续失败 5 次锁 15 分钟

邀请 Token 不放 Cookie
仅存 URL，跨设备可接受

锁定期间任务不中断
文案必须明示「正在进行的任务不受影响」，避免用户恐慌

草稿必须可恢复
会话过期页必须提供未保存内容的恢复入口

协议不可默认勾选
注册协议 Checkbox 默认未勾选，未勾选时主按钮禁用

管理员联系方式必现
所有异常态页面必须提供 <admin@0379.email> 可点击入口
