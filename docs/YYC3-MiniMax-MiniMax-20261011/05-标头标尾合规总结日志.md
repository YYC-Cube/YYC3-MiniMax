## 二、标头格式基线（本次固化的模板）

**代码文件**（规范 §2.1）：

```typescript
/**
 * file: <文件名>
 * description: <≤50字用途>
 * author: YanYuCloudCube Team
 * version: v1.0.0
 * created: 2026-10-11
 * updated: 2026-10-11
 * status: active
 * tags: [类型],[功能],[模块]
 *
 * brief: <≤100字说明>
 * dependencies: ...
 * exports: ...
 */
```

**Markdown 文档**（规范 §1.1 + §1.9）：YAML Front Matter（file/description/author/version/created/updated/status/tags/category/language）→ 品牌标语块 → 正文 → 文末「变更历史」表。

## 四、可追溯迭代机制（后续维护约定）

1. **代码变更**：更新该文件 `updated` 日期；功能级变更 `version` 按 SemVer 递增
2. **文档变更**：更新 FM `updated/version`，并在文末「变更历史」表追加一行
3. **门禁保障**：CI（.github/workflows/ci.yml）tsc/test/build 三段可拦截头注语法破坏（如 `*/` 提前终止）
4. **新文件准入**：创建即携带标头模板；建议后续将「标头存在性检查」纳入 CI lint（Roadmap）
