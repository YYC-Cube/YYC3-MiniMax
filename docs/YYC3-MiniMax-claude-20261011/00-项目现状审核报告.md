## 一、架构概览

### 1.1 分层识别（诊断时）

```
src/
├── components/   UI 组件（含 UniversalWidget W1 浮窗）
├── data/         静态数据层（agents/logs/pipeline/reactSteps/qualityData/opsData）
├── hooks/        useMediaQuery
├── services/     eventStream（LIVE/SIM 双模 WebSocket）
├── types/        index.ts 单一类型事实源
└── views/        P1-P5 + MobileFallback（无路由库，App.tsx useState 切换）
```

### 1.2 关键结论

- 无 pnpm-workspace / features / packages，为单包应用
- 无 domain 层，业务规则内嵌视图；service→data 硬绑定
- tsconfig `@/*` 别名零使用（全相对路径）
- 降级设计优秀（LIVE/SIM 双模、指数退避），但可观测性为零
