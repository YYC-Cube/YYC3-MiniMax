## 遇到的问题与解决方案

| 问题 | 解决方案 | 经验教训 |

| IDE 格式化器 3 次剥离"编辑间隙未使用"导入 → 测试批量红 | CLI tsc 仲裁 + 补回 | 批量编辑 import+调用同提交；编辑后立即 CLI 校验 |
